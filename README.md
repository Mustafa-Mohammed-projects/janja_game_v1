# AboLolo – لعبة قتال تكتيكي (Kotlin / Android)

## البناء عبر GitHub
1. أنشئ مستودعاً جديداً على GitHub وارفع كل محتويات هذا المجلد (بما فيه `.github` و `gradle`).
2. افتح تبويب **Actions** ← **Build AboLolo APK** ← يبدأ تلقائياً عند أي push (أو اضغط Run workflow).
3. بعد النجاح نزّل `AboLolo-apk` من أسفل صفحة التشغيل (Artifacts) وفيه `AboLolo.apk`.
4. لإصدار على صفحة Releases: `git tag v1.0 && git push --tags`.

## استبدال الملفات بملفاتك
- شاشة البداية: `app/src/main/res/drawable-nodpi/presplash.png` (تظهر 3 ثوانٍ على خلفية سوداء).
- أغنية النهاية: `app/src/main/res/raw/endgamelolo.ogg` — إن كانت أغنيتك mp3 فاحذف ملف ogg وضع `endgamelolo.mp3` (لا يجوز وجود الاثنين معاً).

## ما الجديد (النسخة التكتيكية)
- لعبة قتال تكتيكي شبه ثلاثية الأبعاد (2.5D): جنود ومركبات وطائرات ومبانٍ بأبعاد وظلال.
- القادة: السافنا والقبة وأبولو (قوات الجنجا). الأعداء: الفلنقايات، النخب (يتحكمون بالطيران وغرف التحكم)، والدينار.
- 5 معارك بقصة كاملة: خزّان الماء، حماية المسّاحين بمدفع 23 ملم، معركة الخندق، خدعة دار صباح، سقوط النخب.
- أسلحة: مسدس، AK-47، G3، ماغنوس، آر بي جي. زر **إسناد** لقصف مدفعي. سواتر تحجب الرصاص ويحتمي بها الجنود.
- احتفال ورقص في نهاية المعركتين 4 و5 وخاتمة للقصة. يُحفظ التقدّم تلقائياً.
- شخصيات القادة حالياً رسومات مؤقتة؛ سنعدّلها على صورك عند إرسالها (`Looks` داخل `Sprites.kt`).
- لتوليد أصوات الانفجار/المدفع/الطائرة: `python3 tools/generate_assets.py --sfx-only` (الملفات موجودة أصلاً).
